# Number to Words Converter
This is a simple Python script that converts numbers into their English word representation. It can handle up to 15 digits. This project is simply created to practice recursive functions and string manipulation in Python.

## Features
- Converts numbers from 0 to 999,999,999,999,999 into words.
- Includes a simple command-line interface for user interaction.

## Usage
1. Clone the repository or download the script.
2. Run the script using Python 3.
3. Input a number when prompted.
4. The script will output the number in words.

## Example User Interaction

1. In bash, the user runs: `python src/main.py`
2. The program prompts: `Please enter a number in integer format to convert to word(s) or type "exit" to quit:`
3. The user enters: `1234567890`
4. The program outputs: `one billion two hundred thirty four million five hundred sixty seven thousand eight hundred ninety`


## Requirements
- Python 3.x
- No external libraries required, only standard Python libraries.
